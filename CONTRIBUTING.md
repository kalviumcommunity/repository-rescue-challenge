# Contributing Guidelines

Thank you for contributing to the Repository Rescue Challenge!

1. **Branching**: Always create a feature branch using conventional naming (e.g., `feature/<name>`) from `main`. Avoid committing directly to `main`.
2. **Commits**: Write clear, descriptive commit messages following the Conventional Commits specification (e.g., `feat: ...`, `fix: ...`, `docs: ...`).
3. **Pull Requests**: Submit a Pull Request describing your changes, why they are needed, and how they were tested before merging.
